# sop-board 项目总览

SOP 验证协作看板。开发岗的代理用 praxis-skills 的 `sop-verify` 技能推送场景文件、证据与每轮验收结果；测试岗在网页上复核 Agent 判为通过的场景、上传测试用例、按场景提交缺陷；页面展示 Agent 验收通过率、人工复测通过率与测试进度。Web 验收驱动随 sop-board 发行，结果由看板自身登记，不再要求 team-workflow。

任何成员 clone 后用 uv 在本机启动，默认只监听本机，团队共用时由启动者开启内网访问。暂不提供服务器部署。

场景与结果字段由本仓校验器和内置 Web 技能契约维护；保留对既有 sop-verify 文件的兼容。接口、存储与统计口径以 `docs/designs/` 中当前需求的方案为准。

总览优先展示已执行进度、Agent 验收通过率和已复核进度，其他指标可展开查看；所有指标仍采用同一统计口径。队列同时显示转义后的场景名称与编号。复核身份默认折叠，缺少身份时展开并聚焦对应字段；自动刷新保留已展开的配置与指标区域。公共样式采用原生 CSS，窄屏导航横向滚动，表格在区域内滚动，不引入前端框架。
