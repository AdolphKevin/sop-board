# 设置接口分节保存唯一配置，共享库密码可保存在本机配置中

用户确认（2026-11-13）：config.yaml 仍是唯一配置文件。设置接口分七节读取、分节校验与保存；读取磁盘与候选配置共用 Project.read。配置重读先算出完整字段，再一次替换，沿用并发重读教训。

保存核对原字节摘要；占用时拒绝，不停止环境或放弃工作；拒绝本节问题与其他节新增问题。保存重写 YAML，保留一份 config.yaml.prev。共享库 password 可选，省略时交给 libpq；含密码的文件收紧为 600。本机响应与命令输出不带 password 项，不做全文替换。当前已保存的密码只参与内网文本、报告、文本证据与启动日志、运行目录材料的遮蔽；图片、视频、静态资源、verbatim 响应与 Range 片段保持原字节。候选密码不登记，换掉或清除后移除旧值；测试账号凭据维持原有遮蔽范围。密码须为非空文字，不设长度或单行限制，也不裁剪空白（用户返工要求，2026-11-13）。

用户返工要求（2026-11-13）：新密码框留空表示不修改，填入非空内容才提交新密码；去掉“使用新密码”勾选框。只有“清除已保存的密码”操作才改用密码文件；设置接口显式收到空字符串时返回 settings-invalid，field 为 password。产品清单的创建时间与最近写入时间使用看板现有的本机时间格式，当前绑定产品标为“当前产品”并隐藏加入按钮，其他产品仍可加入以换产品。

用户确认（2026-11-13）：共享库连不上、无法确认本机修复是否已经结束时不锁；读取结果 notices 提示“共享库连不上，无法确认修复 #N 是否结束”。只有确认为 open 的修复才占用仓库与共享库，其他工作占用不变。离线时正需要修正连接或密码。

设置页仅接受实际回环连接，顶栏入口只在本机显示。七节逐节保存，问题标在对应字段旁；配置不完整的项目也能启动看板，本机工作台列问题并链接设置页，内网只列类别。会话遇到尚未配置共享连接的项目时给本机设置页地址，由使用者接入；已有连接未绑定时仍列产品并按使用者答复运行 init。会话不读取、不输出 shared_database.password；认证失败引导使用者在设置页改密码。

产品列出、加入和新建复用 products.init/listing；设置接入显式选择产品，文件写失败恢复原文件。断开只撤下机器地址，不搬迁或删除业务记录。本机姓名与机器名先保存到 operator 和 machine.json；共享库不可达时说明机器名尚未同步，下次工作台请求触发登记或看板重启后成功连库时同步，带不带 --lan 都更新。仅操作者姓名变化或机器名不变时不访问业务库。本机配置解析失败保留解析器原始错误、行列和出错内容；连库失败保留驱动原因第一行，只遮蔽已保存密码；认证失败单列，内网只给类别。

## 备选
- 另存设置文件：会出现两个配置来源，拒绝。
- 密码只放密码文件：已定决策 27 为降低接入成本允许本机配置；保留密码文件方式。

## 后果
配置中的密码及上一份副本以明文保存在本机，靠 600 权限保护。不做恢复日志，也不保证跨文件、跨库的崩溃原子性；普通步骤异常恢复原文件。掉电后的连接与绑定不一致、目标产品不存在和临时文件残留，由 status/check 指出问题与人工修法：设置接口、init --join/--new 或直接修改配置。config.yaml.prev 是正常保存的副本，保留并提示用途，不自动恢复或删除。

## 放弃过的做法
- 允许显式空字符串密码，并在页面用“使用新密码（留空也会保存）”控制是否写入。
  放弃原因：使用者确认这会与清除后使用密码文件的操作混淆；页面改为留空不修改，后端恢复非空校验，其余密码限制不增加。
  来源：用户返工要求（2026-11-13），第二段共享库页面三处问题。
  关键词：空密码、留空不修改、清除密码、非空校验。
- 离线时将无法确认的修复作为 unknown 占用并禁止改连接。
  放弃原因：使用者确认离线时不锁，避免阻止排障所需的连接或密码修改；改为只读提示。
  来源：用户确认（2026-11-13），已定决策 27。
  关键词：离线、修复占用、unknown、连接排障。
- 将全部本机响应、命令输出与二进制证据按密码取值替换，并累计候选值和旧值。
  放弃原因：短密码会破坏正常页面和脚本，同值的用户名与库名会被改写，图片字节与摘要会改变。用户确认只在设计规定的文本出口遮蔽当前已保存值。
  来源：用户确认（2026-11-13），已定决策 27。
  关键词：密码遮蔽、短密码、二进制证据、候选密码。
- 配置解析只返回异常类型，本机姓名须业务库先写成功。
  放弃原因：本机工具要能快速定位错误，断网时也要保存本机身份；解析细节保留在本机，机器名以后重连同步。
  来源：用户确认（2026-11-13），已定决策 27。
  关键词：解析错误、行号、列号、本机保存、机器名同步。
