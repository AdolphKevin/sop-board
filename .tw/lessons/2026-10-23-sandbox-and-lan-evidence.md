# 沙箱自检不能替代真实模型与内网入口证据

现象：各段沙箱自检能完成编译、模拟输出消费与本机 HTTP，但真实 Codex 冒烟仍发现会话认领、续接和提示词行为问题；仅核对函数也曾漏掉内网写入响应中返回私有任务字段。Codex 沙箱还可能拒绝启动原生 Codex、浏览器或写入 Git 工作树元数据。

原因：结构正确不代表模型遵循业务要求，本机返回正确也不代表非回环出口经过同一投影。沙箱权限与用户本机环境不同，不能以模拟成功补写真正未走过的链路。

防护：交验收前以真实 --lan 服务同时检查回环与实际非回环地址，保存请求、完整响应、状态码和页面原文；浏览器截图与点击另行留证。私有字段按类型白名单在服务端投影，不能仅靠字符串遮蔽。Codex 沙箱内只读取最近 check 结果，需建立工作树的自检由使用者在沙箱外按已授权范围运行。

模型或浏览器不能运行时，仓库外模拟材料必须逐项注明输出、身份、环境、提交和工作树替代边界；没有原生回执不伪造编号，重放历史回执不称新会话。真实提示词效果、独立交接、复验与工作树恢复由未参与实现的执行者在最终冻结快照上核对。过程证据放仓库外，最终报告把自检、真实冒烟、独立验收分开。

适用条件：改动任务入口、模型提示词、恢复逻辑、页面或 API 的可见字段，以及任何以受限环境完成的交付准备。无需为本教训新增测试。

自检未能运行与自检已完成但不通过必须区分：权限、当前环境缺少运行检查所需的命令、检查器正在被使用或主动中断不能推翻同配置的既有通过记录。不可完成的尝试单独留证，保留原因；实际发现端口占用、规定时限内未就绪，或配置、身份、技能、地址及适配契约有确定错误时，仍按失败处理。任务输入比较不因此放宽，历史失败记录和已作废任务不自动恢复。
