# 梳理交互：生成 Web 入口 $entry 的交互地图（工作 #$work）

前端仓库（别名 → 目录）：$repos

本次范围：$mode

## 你要做什么

只读上面列出的前端源码，梳理用户在这个入口能到达的页面和能操作的界面元素：路由、导航菜单、页面组件、弹窗、表单、表格和多语言资源。

- **只读分析**：不修改源码，不运行产品命令或安装依赖，不访问外部网络。
- **界面语言**：$languages。名称、标题、标签取自多语言文件；没有多语言键的固定文字按源码原样记录，`i18n` 填 null。

## 地图记录什么（只说明“怎么操作”）

**页面**（`pages[]`）：

| 字段 | 内容 |
| --- | --- |
| `id` | 稳定编号，如 `settings.members`；更新已有地图时沿用其中的编号 |
| `title` | 各语言标题 |
| `route` | 路由路径；只是弹出层时填 null |
| `container` | `main`、`iframe:<识别说明>` 或 `new-tab` |
| `reach` | 从起点（`from` 为 `start`）或其他页面经哪个控件到达（`via` 为控件引用，直接打开地址时为 null） |
| `ready` | 打开后能看到的就绪信号，如“标题 Members”“按钮 Invite members” |
| `controls`、`dialogs`、`tables` | 页面上的控件、弹窗、表格，见下表 |
| `sources` | 源码位置 |
| `verified_browser` | 浏览器核对日期；没有核对时为 null |

**控件**（`controls[]`）：

| 字段 | 内容 |
| --- | --- |
| `id` | 页面内唯一 |
| `role` | button、link、menuitem、tab、textbox、combobox、checkbox、radio、switch 等 |
| `name` | 各语言可访问名称 |
| `i18n` | 多语言键 |
| `locator` | 推荐的 Playwright 定位器，优先级为 `data-testid`、`getByRole` 加名称、文字 |
| `testid` | `data-testid` 的值 |
| `opens` | 打开的对象：`page:<页面编号>`、`dialog:<弹窗编号>`、`menu`，或 null |
| `requests` | 点击后发出的请求（方法与路径），作为等待依据 |
| `sources` | 源码位置 |

**弹窗**（`dialogs[]`）：编号在整份地图内唯一，包括标题、定位器、字段（编号、角色、各语言标签、多语言键、定位器、`testid`）、操作按钮（同控件）和源码位置。

**表格**（`tables[]`）：编号、定位器、列（编号、各语言标题、多语言键）、行操作（同控件）、各语言的空状态文案、源码位置。

**写法约定**：

- 控件引用写成 `<页面>/<控件>`；弹窗或表格里的操作写成 `<页面>/<弹窗或表格>/<操作>`。
- 源码位置写成 `<仓库别名>:<仓内相对路径>` 或 `<仓库别名>:<仓内相对路径>:<行>`，行号从 1 开始。
- 页面文案所在的多语言文件也写进该页面的 `sources`，不写行号。看板按源码摘要判断页面是否过期。
- 各语言文案用 `[{"lang": "en", "text": "Invite members"}, {"lang": "zh", "text": "邀请成员"}]` 的形式。

## 地图不能记录什么

地图只告诉执行者“在哪、叫什么、怎么定位、点了打开什么、发出什么请求”。以下内容是业务预期，属于场景，不得写入：

- 谁能看到或操作（角色、权限、可见性）；
- 校验规则（长度、必填、格式、范围）、默认值；
- 点击后的业务结果、状态变化、提示是否成功、副作用。

按代码推断这些行为也不要写，把当前实现写进地图，就等于把它当成了正确答案。输出结构不接受额外字段。

## 输出

把结果写成符合 $schema 的 JSON 文件：$target（目录不存在就建立）。

| 字段 | 内容 |
| --- | --- |
| `pages` | 本次写出的页面（全量模式为全部页面） |
| `removed_pages` | 已不存在的页面编号 |
| `feedback_handled` | 写空数组 |
| `notes` | 本次梳理的范围说明与无法确定之处 |

然后运行 `sop-board atlas submit --entry $entry`：它校验结构与源码位置，并在旁边写入引用源码的摘要，之后据此判断过期。地图文件留在仓库里，由开发者审核提交。
